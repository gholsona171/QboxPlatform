> The product is called **Guildhall**. "Qbox" and "QboxPlatform" below are the code name, still used for package, service, and repository names.

# Vision

Build a production-grade modular platform supporting:

- Discord.
- FiveM / Qbox.
- Shared libraries.
- Future AI integrations.

# Core Principles

Security before convenience.

Architecture before speed.

Maintainability before cleverness.

Documentation is mandatory.

Every feature should be testable.

Every feature should be modular.

# Long-Term Goals

- Production-ready.
- Enterprise-quality architecture.
- Modular services.
- Minimal technical debt.
- Automated testing.
- Strong documentation.
- Reusable packages.

# Engineering Rules

Prefer improving existing systems over creating new ones.

Never duplicate functionality.

Reuse packages whenever possible.

Never bypass dependency injection.

Avoid global state.

Keep modules independent.

# AI Philosophy

Before writing code:

1. Inspect.
2. Understand.
3. Plan.
4. Wait for approval.
5. Implement.
6. Validate.
7. Review.

# Definition of Done

A feature is complete only when:

- Implementation is complete.
- Documentation is updated.
- Validation has been run.
- Git diff has been reviewed.
- No unnecessary files were created.
